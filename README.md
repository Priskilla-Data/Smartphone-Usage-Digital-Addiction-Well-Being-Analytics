# 📱 Smartphone Usage, Digital Addiction & Well-Being Analytics

## 📌 Project Overview
This project analyzes smartphone usage patterns, digital addiction, and well-being using **Microsoft Power BI**.

The dataset contains **7,500 user records and 16 attributes** related to screen time, social media, gaming, sleep, stress, notifications, and app usage.

## 🎯 Objectives
- Analyze smartphone screen time and usage patterns
- Understand different addiction levels
- Analyze social media and gaming usage
- Study sleep and stress-related patterns
- Compare usage across age groups and genders
- Create an interactive Power BI dashboard

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- Power BI Visualizations

## 📊 Dashboard Features
- KPI Cards
- Slicers and Filters
- Bar/Column Charts
- Donut Chart
- Line Chart
- Scatter Chart
- Decomposition Tree
- Key Influencers

## 📈 Key Metrics
- Total Users: **7,500**
- Average Daily Screen Time: **7.50 hours**
- Average Weekend Screen Time: **9.24 hours**
- Average Sleep: **6.74 hours**
- Average Social Media Usage: **3.27 hours**
- Average Gaming Usage: **2.01 hours**
